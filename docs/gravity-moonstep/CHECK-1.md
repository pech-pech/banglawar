# CHECK-1: audio.js / fx.js / draw.js review (read-only, 2026-11-19)
Files: pages/gravity-moonstep/src/{audio,fx,draw}.js. tests/fx.js passes. No Math.random/Date/performance.now in any of the three (audio noise buffer, fx emit and draw textures all use local seeded LCGs). No throw paths found: every public audio call is try/catch; fx and draw have no unguarded DOM access.

## Ranked findings
1. MED audio.js:156-186 (tideLevel) and 100-117 (charge), called every frame from game.js:399-400. Each call queues 3 setTargetAtTime events on the audio timeline, so ~180 automation events/s pile up. Fix: cache the last sent value and return early when |level - last| < 0.01 (quantise to 1/64), and only update the LFO rate when it changes.
2. MED audio.js:41-62, 74-90 (tone, noise). No guard for ctx.state !== 'running'. In a hidden or suspended tab currentTime freezes, events queue, and they all burst on resume. Fix: `if (ctx.state !== 'running') return;` at the top of both. Also no voice cap on jump/land/chain/medal spam.
3. MED draw.js:209-217 and 201 (bodySprite, ensure). Per-frame string-key allocation per visible body, plus the `sig` string in ensure(). Worse, line 213 does `cache.bodies = {}` when nb > 48, so the next frame rebuilds every visible sprite (buildBody is expensive) and stutters on long runs. Fix: store the sprite on the body (`b._sp`, with `_spk` as a numeric signature of kind, round(r) and scale) or use LRU eviction of one entry instead of a full flush. Compare numeric view fields instead of building a sig string.
4. LOW-MED fx.js:84-98 (draw). If w2s returns a new array, that is up to 184 allocations per frame (game.js:43 does exactly that), and line 96 builds an 'rgb(..)' string per particle. This contradicts the contract's "no per-frame allocation". Fix: precompute `KIND_FILL = KIND_COL.map(c => 'rgb(' + c + ')')`. Let the game's w2s write into a reused 2-element array (safe, since fx reads p[0] and p[1] immediately), or add an optional `view.camY` / `view.w` fast path in fx.draw. Also batch the arcs per kind to cut state changes.
5. LOW draw.js:258-260. `b.id` is used with no `|0` guard (line 145 does guard it). If a body lacks an id, the repel pulse phase is NaN and the ring silently vanishes. Per-frame `.toFixed(3)` and `INK2 + '0.3)'` string concats (lines 244-253, 260, 354) add GC churn. Fix: `(b.id|0)`, and precompute the alpha strings.
6. LOW draw.js:31-33. `MoonDraw.worldToScreen` returns `{x,y}` but fx.draw expects `[sx,sy]` (contract: w2s(x,y)->[sx,sy]). Currently harmless because game.js:43 defines its own w2s, but it is a trap and allocates per call. Fix: remove it or return a shared array `[x,y]`, and state this in the contract.
7. LOW fx.js:41 vs audio.js:132. Land intensity normalises vn by 300 in fx and 400 in audio, so a hard-hit visual (q>0.55 means vn>165) triggers well before the sub boom (v>0.6 means vn>240). Fix: one shared constant, e.g. 400 or C.VMAX.
8. LOW fx.js:60. Damping `1 - 2.5*dt` is frame-rate dependent. Fix: `Math.exp(-2.5*dt)`. fx.js:30 shake amplitude is in CSS px and ignores view.scale (fine for the CSS transform used in game.js:414).
9. LOW audio.js:66-71. Noise buffer is 0.5 s but over() asks for 0.7 s noise (line 197), so it is cut at 0.5 s (inaudible tail). Fix: 1.0 s buffer or loop = true. audio.js:8 `lastChain` is a dead store. Charge osc start/stop has no ramp (clicks on release, lines 104-109, 94). Fix: ramp gain to 0 over 15 ms before stop.
10. INFO Reduced motion. fx shake/pause are gated (fx.js:30-31). draw.js freezes tide waves (361) and repel pulse (258-260). Remaining gap: fx trail and particles still animate in reduced mode. This is allowed by the contract (no shake/pulse/flash), but consider skipping the trail when `reduced`. game.js:39 rebuilds fx on a reduced change and so drops live particles (harmless).
11. INFO API vs POLISH-CONTRACT: audio has init, setEnabled, charge, jump, land, chain, tideLevel, over, medal, near, bounce, crumble, tick. fx has make, event (6 names), update, shake, pause, draw, trail, plus extras clearTrail, live, reduced. All match; no breaks.
