## FIXES to concept D (admin default; from review-2)
- Jump speed v = 200 + (min(charge,0.45)/0.45)*180  => 200..380 px/s (min hop apex ~55 px; max charge does not escape). Chain bonus x1.10 if jump within 0.08 s of landing.
- View: S = portrait narrow (innerWidth/innerHeight < 0.55, e.g. 344x882): world scale = innerWidth/344, runner at 38% from top. W = otherwise (e.g. 475x638): world scale 1.0 (shows 475 wide), runner at 45% from top. Generator keeps body x within [-150,150] around centre 0. Thumb zone = bottom 42%. Look-ahead shifts runner down <= 8% during fast climb.
- Generator reachability check: a candidate body is accepted only if the engine's own predict() from the previous body (still, spin 0) can land on it for some rim angle (step 15 deg) and charge (0,.1,.2,.3,.45). Try up to 8 candidates (distance shrinks 10% each retry), else last-resort 90 px gap. Reachability uses no rng.
- Ownership: strongest pull a_i is owner (100%); every other attractor in range adds 35%; owner changes only when a challenger > 1.15 x current owner pull. Repel bodies are never owner; they push at 100% inside R. Repel is solid (d<=r+9: reflect, restitution .35).
- Hysteresis stays in (admin default); assist arc default ON, toggle in settings.
- Report logs "aimed vs landed" per jump so "skill not luck" is measurable.

## engine.js: global `Moonstep` (pure, no DOM, no Date, no Math.random)
Constants in `Moonstep.C`: DT=1/120, RUN=90, RUNNER_R=9, VMAX=520, JUMP_MIN=200, JUMP_RANGE=180, CHARGE_MAX=0.45, STICK_VN=380, REST=0.35, CHAIN_WIN=0.08, CHAIN_BONUS=1.10, OWN_EXTRA=0.35, OWN_HYST=1.15, TIDE0=22, TIDE_ACC=0.2, TIDE_MAX=60, LOST_T=1.2, G0_BASE=900 (at r=60, g0=900*(r/60)^0.5), RANGE_K=3.2 (R=3.2r, pull fades linearly to 0 over outer 25% of R), SPIN_MAX=0.6, CRUMBLE_T=1.5, FLICK/CANCEL are input-only.
World: y grows DOWN (screen style), "up" = -y. Start body id 0 at (0,0) r=80, runner on its top. Height m = max(0, -minRunnerY)/10 (floored on report). Tide starts at y=+260 and rises (y decreases) at TIDE0+TIDE_ACC*t capped TIDE_MAX px/s; opts.tideScale multiplies the rate (difficulty setting, default 1).
API:
- `Moonstep.hashSeed(str)->u32`, `Moonstep.rng(u32)->()=>[0,1)` (mulberry32). Generation uses ONE rng stream drawn only inside body generation; bodies are generated lazily to stay >= 1200 px above the runner's best height, and their content depends only on seed+index (never on input).
- `s = Moonstep.newRun(seedStr, opts)` opts {tideScale:1}. State (all plain JSON-able numbers): s.seed,s.tick,s.t,s.over,s.cause('tide'|'lost'|null), s.bodies[]{id,x,y,r,g0,R,kind:'still'|'spin'|'crumble'|'repel',spin,ang,rem(radius left, crumble),dead,left(bool)}, s.runner{x,y,vx,vy,mode:'rim'|'air',body,theta,dir(+1|-1),vt(rim speed),charge,charging,sinceLand,bounced,lostT}, s.owner, s.tideY, s.height, s.jumps, s.chain, s.bestChain, s.jumpLog[]{tick,charge,aimed,landed,chain}, s.log[] (input events [tick,code]: 1=down edge,0=up edge(release=jump),2=reverse,3=cancel).
- `Moonstep.tick(s, inp)` advances exactly one DT. inp={down:bool, reverse:bool(one-shot), cancel:bool(one-shot, only while charging)}. Release edge = jump (only if on rim; in air release does nothing). Charge builds while down on rim, caps at CHARGE_MAX. No-op when s.over. Semi-implicit Euler: velocity then position. Rim: theta += (dir*RUN/r + spin)*DT for the body; vt decays to RUN at 200 px/s^2 after landing (landing tangential speed capped 240). Landing contact d<=r+RUNNER_R on owner or any attractor; vn<=STICK_VN sticks, else one bounce (REST) then stick. Lost: outside every live attractor's R for LOST_T. Speed capped VMAX. Crumble: when runner leaves it, rem shrinks to 0 over CRUMBLE_T, then dead (landing during shrink allowed; contact radius = rem).
- `Moonstep.predict(s, chargeSec, maxSteps=60)` -> {pts:[{x,y} every 4 steps], landId(-1 if none within maxSteps), steps}. Simulates "release now" on a cheap copy: only runner state is copied, bodies are static in space (spin only rotates rim), crumble ignored. Must be allocation-light (called per frame). With maxSteps=900 it is used for `aimed`.
- `Moonstep.report(s,extra)` -> object {v,seed,height,jumps,bestChain,cause,ticks,seconds,aimedHit,aimedTotal,hash,inputLog(string "tick:code,..."),extra}; `Moonstep.hash(s)` = stable string of height+jumps+tick+round(x,y). `Moonstep.replay(seedStr, logString|array, opts, maxTicks=240*120)` -> final state (plays the log; after the last event keeps ticking with no input until s.over or maxTicks).
- Medals: `Moonstep.medal(height)` -> 'Moon'>=1500,'Gold'>=800,'Silver'>=400,'Bronze'>=150,else ''.
- Daily seed helper `Moonstep.dailySeed(yyyymmddString)` -> 'D'+string.
Kinds ramp by height m: crumble share 0->35% at 600 m, spin share 0->35% at 400 m, repel 0->15% at 800 m; first 4 bodies after start: big (r 70-90), still. Body r 36..90, gap centre-to-centre 90..230 up +-70 deg, >=20 px rim gap.

## audio.js: global `MoonAudio` (Web Audio tones only, no files). API: init() (call on first touch), setEnabled(bool), charge(level0..1) (rising pitch while charging; call each frame, silent when level<=0), jump(), land(vn), chain(n), tideLevel(0..1) (low rumble gain), over(), mute persisted by game. Respect prefers-reduced-motion irrelevant; never throw.

## game.js (render, input, UI, loop; no globals except via IIFE)
Canvas 2D, devicePixelRatio aware, fixed-step accumulator at DT, clamp frame delta to 0.1 s. Input: pointer down/up anywhere in thumb zone = hold/release; flick >= 40 px horizontal in < 150 ms while down = reverse; drag down 60 px while charging = cancel. Buttons 56x56: Pause top-left, Copy report top-right (never in thumb zone). HUD: height m, medal next band, chain meter, seed code. Plain shapes per concept section 2: runner white circle r9 + tail line, bodies grey circles with influence ring + rim notch (spin), dashed rim (crumble), pulsing outward ring (repel), tide dark band with bright top edge. Assist arc dotted 0.5 s while charging (toggle). Game over overlay ignores taps for 600 ms, shows height, medal, cause, buttons: Retry same seed, New seed, Copy report, Verify replay (replays log via Moonstep.replay and shows OK/FAIL by comparing hash). Pause menu: assist toggle, sound toggle, tide speed (0.75/1/1.25), daily seed button, seed text. Local best per seed + attempt list (last 20: seed,height,jumps,chain,cause) in localStorage with try/catch, never downgrade a best. Copy report copies JSON of Moonstep.report + attempts + input log + view key + renderer 'canvas2d' + 'WebGPU output: NOT seen' + frame time p50/p95; fallback to a textarea overlay if clipboard fails. Reduced motion: no pulsing/shake. Safe-area insets honoured. `?seed=XXXX` URL param.
Exposed for tests only: `window.__moon = {state:()=>s, step:fn}`.

## SPLIT ADDENDUM (files and who owns what; overrides placement above)
Load order: audio.js, engine.js, gen.js, draw.js, game.js.
- engine.js (global `Moonstep`): everything in the engine section EXCEPT body generation. On `newRun` it calls `MoonGen.init(s, seedStr, opts)`; on every tick (and after a landing) it calls `MoonGen.ensure(s)`. Also exports `Moonstep.probe(prevBody, candBody, thetaDeg, charge)` = `predict` on a temp 2-body state, used by gen.
- gen.js (global `MoonGen`, UMD): `init(s,seedStr,opts)` sets s.gen={rng,next index,...}, s.bodies=[start body id0 (0,0) r80 still, then 4 big still safe bodies,...]; `ensure(s)` appends bodies until the topmost body is >= 1200 px above min(s.runner.y, best y). Body: {id,x,y,r,g0,R,kind,spin,ang:0,rem:r,dead:false,left:false}. Reachability check via `Moonstep.probe` (see FIXES). Pure of input; no Date/Math.random. Kind ramps and distances per engine section.
- draw.js (global `MoonDraw`, UMD, no DOM except the passed ctx): `MoonDraw.frame(ctx, s, view, ui)` where view={w,h,dpr,scale,runnerFrac,camY,key:'S'|'W'} and ui={pred:{pts}|null, charge01, reduced:bool, t}. Draws world + tide + runner + assist arc + notches. `MoonDraw.makeView(w,h)` -> view for S/W rule. `MoonDraw.camera(s, view)` -> camY with look-ahead (<=8%). `MoonDraw.worldToScreen`. Never reads the DOM.
- game.js: loop, input, HUD text, buttons, overlays, storage, report/verify, URL params. Uses MoonDraw, Moonstep, MoonAudio.
- audio.js, index.html/manifest/sw/icons as above. tests/ in Node (no browser) and a Playwright smoke in tests/e2e.js.
