# Moonstep UI design contract (Ink and Moonlight)
Tokens: paper #f8f1dd / #f0e7d1 / edge #d9cfb8; ink #15171f / #0d0f16; moon silver-blue #bcd0ee #a9bcdc; ochre #8a5a14; vermilion #8e2a1c. Fonts: system serif for titles (Georgia, 'Times New Roman'), system sans for numbers. Double ink border (2px + 1px gap), wobbly hand-drawn edges (SVG/canvas), paper grain, dotted ink lines, silver halo on focus. Touch targets >= 56 px. Fold cover 344x882 first, also 475x638. Thumb zone (bottom 42%) holds only the hold-to-jump area during play; menus put primary buttons in lower third. Reduced motion: no pulses.
Output per maker: pure HTML+CSS (no assets, no libs) in docs/gravity-moonstep/ui/<screen>.html, each screen rendered with Playwright (require('playwright'), chromium.launch(), 344x882 dpr2) to ui/<screen>.png, plus ui/<group>-NOTES.md (components, sizes, states, copy text). No web, no extra skills. Reply 5 lines + paths.
Existing features that need UI: medals Bronze 150/Silver 400/Gold 800/Moon (bands may change, show as variables), pause menu (assist arc, sound, tide 0.75/1/1.25, seed text, daily seed), game over (height, medal, cause tide/lost, Retry same seed, New seed, Copy report, Verify replay OK/FAIL), best per seed, last 20 attempts, Copy report, ?seed=, install prompt.
Groups: A = title/menu + how-to-play (3 steps: hold, aim, release; flick reverses; drag down cancels) + install hint. B = in-play HUD (height pill, next medal, chain meter, tide warning, pause + copy buttons, seed code) + pause menu + settings (sound, assist, tide speed, reduce motion, reset). C = results screen per medal (none/Bronze/Silver/Gold/Moon, new best state, cause line) + best-by-seed list + attempts list (20 rows) + medal sheet.
