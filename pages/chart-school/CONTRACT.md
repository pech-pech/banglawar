## CHARTING CONVENTIONS (follow M's dse-pnf / Dorsey method where it differs from the old engine; engine.js is the single source)
Bars: weekly {h,l,c}, normalised by the first shipped close (price 1.0 = first close). Display price = p*100 (integer when >=100, else 1 decimal).
C1 Box: 2% log box (M's pick P2; masking needs a percent box). boxOf(p)=floor(ln p/ln 1.02 + 1e-9) for highs and closes; boxUp(p)=ceil(ln p/ln 1.02 - 1e-9) for lows. A high fills box b only when high >= price(b); a low fills b only when low <= price(b). priceOf(b)=1.02^b.
C2 Reversal 3 boxes, high/low method, one direction per week, Dorsey order: in an X column first check the high for new X's; only if none, check the low for a 3-box reversal (lowBox <= hi-3 -> new O column from hi-1 down to lowBox). O column mirror (highBox >= lo+3 -> new X column lo+1 .. highBox).
C3 First column: bar 0 makes an X column from boxUp(l) to boxOf(h) (if lo>hi then lo=hi).
C4 Signals (Dorsey): buy = X column exceeds the top of the X column two back (j-2) by 1+ box; triple top buy when the X column four back (j-4) has the same top as j-2; mirror for sells. A column fires at most once; the signal belongs to that column.
C5 Bullish Support Line (Dorsey BSL): anchor = lowest O box among the last 30 columns (ties: EARLIEST column); line starts 1 box under it and rises 1 box per column: lineBox(col j) = anchorLo - 1 + (j - anchorCol).
C6 Vertical count (M's dse-pnf rule, CHANGED from the old engine): count column = the buy SIGNAL column found by R1 (in the last 3 columns). boxes = hi - lo + 1 of that column at week W (provisional if it is the current column). objective box = lo + 3*boxes (log box, so the count is in boxes). Discard the sheet's R4 when the signal column index <= 1.
C7 "Completed" column = any column that is not the current (last) column.

## READING TYPES (answers from CSE.readAll(bars) on exactly the shipped bars up to week W)
R1 Signal (last 3 columns incl. current; later column wins): "Double top buy","Triple top buy","Double bottom sell","Triple bottom sell","No signal".
R2 Support box: lo of the most recent completed O column (answer = box index). R2b Resistance box: hi of the most recent completed X column. A sheet asks R2 OR R2b (sheet field r2key).
R3 Trend line, 3-way: d = closeBox - lineBox(current col). "Above by 3+ boxes" (d>=3) / "Within 2 boxes above" (d=1..2) / "On or below" (d<=0). Discard only when no O column in the last 30 columns.
R4 Vertical count objective (only when R1 is a buy): box index per C6. Tolerance 0.
R5 RSI(14 weekly closes, Wilder; first value 50, simple-average seed weeks 1-14): "Above 70","50 to 70","30 to 50","Below 30". Discard if within 1.0 of 30/50/70.
R6 MACD(12,26,9, EMAs seeded with first value; hist = macd - signal): "Positive rising","Positive falling","Negative rising","Negative falling" (sign of hist at W, direction vs W-1). Discard if |hist| < 0.02*box or |hist change| < 0.005*box, box = priceOf(closeBox+1)-priceOf(closeBox).
R7 Divergence (tested at t = W and W-1, t>=12): Bearish if close[t] > max of the 12 prior closes and RSI[t] < RSI at that prior max (latest on ties); Bullish mirror with lows; "None" otherwise; both = discard. Options "Bearish","Bullish","None".
Accuracy record pools R2 and R2b as "Support / resistance". Display names: R1 Signal, R2 Support / resistance, R3 Trend line, R4 Vertical count, R5 RSI, R6 MACD, R7 Divergence.

### engine.js (global `CSE`; in node `module.exports = CSE`)
CSE.boxOf(p), CSE.boxUp(p), CSE.priceOf(b), CSE.disp(p) -> price label string (p*100).
CSE.pnf(bars) -> {cols:[{d:1|-1, lo, hi, start:weekIdx, end:weekIdx, sig:0|1|-1, sigName:null|R1 option text, sigWeek:null|weekIdx}], colOfWeek:[column index at each week], cells:[{col, box, week}] (week when each box was first filled, for "new" drawing)}
CSE.rsi(closes) -> array; CSE.macd(closes) -> {macd:[], signal:[], hist:[]}
CSE.readAll(bars) -> {R1:{answer, col}, R2:{answer, col}|null, R2b:{answer, col}|null, R3:{answer, anchorCol, anchorLo, lineAtCur, closeBox, d}|null, R4:{answer, col, boxes, from}|null, R5:{answer, value}|null, R6:{answer, hist, prev}|null, R7:{answer, t, ref}|null, disc:{type:reason}}
CSE.OPTIONS = {R1:[...], R3:[...], R5:[...], R6:[...], R7:[...]} (exact texts above). CSE.TYPES=["R1","R2","R2b","R3","R4","R5","R6","R7"]. CSE.NAMES = display names (R2b -> "Support / resistance").
CSE.RULES[type] = {title, lines:[3-6 plain sentences]}: the one-screen "Review rule" card stating the convention (C1-C7) for that type. Example R4: "Find the buy signal column. Count its boxes, low to high. Multiply by 3. Add that many boxes above the column's lowest box. Each box is 2%, so the objective is counted in boxes."
CSE.explain(type, reads, given) -> one plain sentence for the marked view, right or wrong, with display prices (e.g. "Marked: off by 1 box. The count starts at the column's lowest box, 102." / "Right: RSI 63 sits between 50 and 70.").

### data/sheets.json (GEN)
{build:"cs-proto-1", seed, conventions:"C1-C7 short text", base:{up10, n}, sigStats:{"Double top buy":{n, follow}, ... 4 signals}, sheets:[{id:"S0001", stock:int, bars:[[h,l,c],...], fwd:[[h,l,c] x10], r2key:"R2"|"R2b", ans:{R1, R2 or R2b, R3, R4 (null unless R1 is a buy), R5, R6, R7}}]}
bars = last min(120, W+1) weeks up to W, normalised by bars[0].c, 5 decimals; fwd = next 10 weeks, same normaliser. ans MUST equal CSE.readAll(bars) answers (GEN asserts). Keep a sheet only when R1, r2key, R3, R5, R6, R7 all have answers and (R1 is a buy) == (R4 exists). Min 60 weeks history, min 12 columns, 8-week spacing per stock.
sigStats/base from all weeks of all stocks (full history, CSE.pnf on full normalised history): follow = share where close +10 weeks is above (buy) / below (sell) the signal-week close; base.up10 = share of all weeks with close +10 above.
BALANCE: pick about 240 sheets by greedy joint balancing from a 50,000-draw pool so each type's answer classes are as equal as the data allows (R1 5 classes, R3 3, R5 4, R6 4, R7 3; R2/R2b/R4 by distance bucket from close). Report the achieved mix. Target file size under 1.2 MB.
Bot gate (test/bots.test.js, node, exit 1 on fail): on shipped sheets, per type, random / most-common / first-option bots each under 40% (stepper types: random row, most-common offset from close, lowest/highest visible row); share of sheets where a bot gets 6+ of 7 under 1%.

### chart.js (CHART) pure SVG, no libs, globals drawPnf, drawRsi, drawMacd
drawPnf(host, opt): renders SVG into host. opt = {bars, eng (CSE.pnf result), newFrom: weekIdx|null (boxes first filled at/after this week drawn as "new": outlined + brighter), cols: last N columns shown (default 24), showColNums, overlays:[...], pick: box|null (player's current row, drawn as dim dashed line), onRow: fn(box)|null}. Overlay kinds: {k:"row", box, label, style:"pick"|"engine"}; {k:"line", box, label, style:"engine"|"pick"} dashed horizontal; {k:"col", col, label} outlined column; {k:"bsl", anchorCol, anchorLo} 45-degree line (accent colour, label "support"); {k:"sig", col, label} chip/arrow at the signal column; {k:"close", box} marker at last close. Right price axis with display prices every 2 boxes; column axis below. Row tap: invisible full-width rects; tap selects the nearest row and calls onRow(box) (stepper fine-tunes, 48px rule met by the stepper). Blue X (var --x) / orange O (var --o); colour never the only signal. About 300px tall at 344 wide; width = host width.
drawRsi(host, closes, opt) and drawMacd(host, closes, opt): last 26 weeks (opt.newFrom shades weeks >= newFrom); RSI guides 30/50/70; MACD solid line, dashed signal, histogram bars; values go in the pane header (screens), not inside the plot (VQA fix 8). opt.mark: {t} draws a small marker at week t (R7 reference).
